# K1NGMR

Personal portfolio for Ananda Thapa, also known as K1NGMR.

This site brings together the Nexara ecosystem, Minecraft systems, game plugins, security experiments, and the product work behind them.

## Featured work

- **Nexara**: an AI product ecosystem spanning web, mobile, Windows, IDE, and CLI experiences.
- **Minecraft systems**: plugins covering gameplay, economy, progression, moderation, and server security.
- **Signal Loom**: a web-ready 3D object used to represent ideas moving through connected tools.

## Run locally

```bash
npm install
npm run dev
```

The site runs at `http://localhost:3000`.
